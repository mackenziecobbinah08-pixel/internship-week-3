# Country Info App

Using OpenCode, I developed a country lookup app powered by the REST Countries API.

## Features

- Search for any country
- Displays flag, capital city, population, region, and languages spoken
- Handles loading, error, empty, and success states

## Tech Stack

- React + Vite
- REST Countries API (no API key needed)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
